ABOUT :

A secure hardware token built using the ESP32 that requires physical button confirmation before processing sensitive data. Integrating embedded firmware, on-chip Non-Volatile Storage (NVS) for persistent credential encryption, finite state machines, and a Web Serial interface, all encryption and verification decisions remain isolated within microcontroller silicon.

● SECURITY ARCHITECTURE & HARDWARE AIRGAP
100% HW CRYPTO / HW ACCEPT & REJECT / NVS FLASH / TACTILE AIRGAP
[01] TACTILE AIRGAP

PHYSICAL BUTTON 2FA

Eliminates automated remote malware execution. Cryptographic commits remain locked in hardware memory until the operator physically depresses the on-board tactile button (GPIO0 interrupt).

[02] ON-CHIP CRYPTO

100% HARDWARE ENCRYPTION

All encryption and hashing are performed directly on the microcontroller hardware. The browser/host never executes cipher algorithms or holds encryption keys, preventing host memory dumps.

[03] AUTONOMOUS GATE

HARDWARE ACCEPT / REJECT

Verification is decided strictly on hardware. The ESP32 independently validates candidate credentials and issues the authoritative ACCEPT or REJECT verdict—client software cannot tamper with decisions.

[04] SECURE MEMORY

NVS FLASH STORAGE

Encrypted credentials are saved directly to ESP32 Non-Volatile Storage (NVS) flash partitions. Zero disk footprints, cookies, or browser cache—data remains securely isolated on-chip across reboots.
